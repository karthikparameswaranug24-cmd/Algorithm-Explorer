# Algorithm Explorer

A Flask-based web application for learning, visualizing, and experimenting with Data Structures and Algorithms using Python.

---

## Motivation

This project is being built to strengthen my understanding of Data Structures, Algorithms, Python, and Flask by implementing algorithms from scratch and making them interactive.
